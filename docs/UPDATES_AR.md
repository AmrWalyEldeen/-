# تحديث البيانات لاحقاً

بعد تشغيل الموقع تصبح قاعدة البيانات هي مصدر الحقيقة، والتعديل اليومي يتم من الواجهة نفسها ثم يُحفظ تلقائياً.

## تعديل النصاب

من **إدارة المواد والأعضاء والنصاب** عدّل عدد الساعات أمام الدرجة العلمية. يتغير المستهدف لكل أعضاء الدرجة فوراً، إلا العضو الذي تم وضع نصاب خاص له.

## المقررات والبرامج الخاصة

لكل مقرر يمكنك تحديد:
- نوع البرنامج: عام / خاص / أخرى.
- طريقة الاحتساب: داخل النصاب / إضافي / لا يُحسب.

هذا التصنيف مستقل، لذلك يمكن أن يكون المقرر «برنامج خاص» ولكن تختار طريقة حسابه حسب قرار القسم.

## إضافة أو حذف مادة

يمكن إضافة مادة جديدة من نموذج إدارة المواد. حذف مادة مستخدمة سيطلب تأكيداً لأن الجلسات المرتبطة بها وتكليفاتها ستُحذف.

## إضافة أو حذف عضو

اختر الهيئة المعاونة أو هيئة التدريس، ثم أضف الاسم واللقب والدرجة والتخصص عند الحاجة. حذف عضو مكلف يزيل تكليفاته بعد التأكيد.

## وصول Excel جديد

عند وصول ملف Excel أحدث، الأفضل مقارنة بياناته بقاعدة البيانات ثم تطبيق التغييرات فقط: المواعيد، الأسماء، التكليفات، المواد الجديدة، والأعضاء الجدد. الإحصائيات والساعات والتعارضات تُعاد حسابها داخل الموقع من البيانات الأساسية.

قبل أي استيراد كبير نزّل Backup JSON من صفحة الإعدادات.


> مبدئياً تم تصنيف مقررات `BTBIO` كـ **برنامج خاص / ساعات إضافية**، ويمكن تغيير ذلك من صفحة الإدارة في أي وقت.
