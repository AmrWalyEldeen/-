# نموذج البيانات — Web v2

## role_targets
قواعد النصاب المستهدف حسب الدرجة العلمية. المفتاح هو:
- نوع العضو: `assistant` أو `faculty`.
- الدرجة العلمية.

كل عضو يأخذ نصابه من درجته تلقائياً، إلا إذا تم إدخال `target_override` خاص به.

## courses
كتالوج المواد. يحتوي على:
- الاسم والكود.
- `program_type`: نوع البرنامج مثل برنامج عام أو برنامج خاص.
- `workload_mode`:
  - `target` = داخل النصاب.
  - `extra` = ساعات إضافية.
  - `excluded` = لا تُحسب.
- التخصص.
- هل الإشراف مطلوب افتراضياً.
- الحالة النشطة والملاحظات.

## assistant_people
قائمة الهيئة المعاونة: الاسم، اللقب، الدرجة العلمية، الترتيب، النصاب الخاص إن وجد، والحالة.

## faculty
قائمة أعضاء هيئة التدريس: الاسم، اللقب، الدرجة، الحالة، التخصص، النصاب الخاص إن وجد، والحالة النشطة.

## sessions
مصدر الحقيقة للمواعيد والمعامل. كل سجل يمثل معمل واحد في جلسة واحدة ويحتوي اليوم، من، إلى، المادة، رقم المعمل، التخصص، وهل الإشراف مطلوب.

الجلسة مرتبطة بالمادة عن طريق `course_id` مع الاحتفاظ باسم المادة أيضاً لسهولة القراءة والتوافق.

## assistant_assignments
يربط كل Session بأعضاء الهيئة المعاونة بترتيب 1–5.

## supervisor_assignments
يربط كل Session بأعضاء هيئة الإشراف بترتيب 1–10.

## change_log
سجل تلقائي لتغييرات الجلسات والتكليفات والأعضاء والمواد وقواعد النصاب عند استخدام Supabase.

## طريقة حساب الساعات

لكل تكليف يؤخذ طول الجلسة:
- إذا كانت المادة `target` تضاف إلى ساعات داخل النصاب.
- إذا كانت `extra` تضاف إلى الساعات الإضافية.
- إذا كانت `excluded` لا تدخل في الحساب.

الفرق عن المستهدف = **ساعات داخل النصاب - النصاب المستهدف**.


> مبدئياً تم تصنيف مقررات `BTBIO` كـ **برنامج خاص / ساعات إضافية**، ويمكن تغيير ذلك من صفحة الإدارة في أي وقت.
